#Energy-Planner
This project is an independent project that aims to learn and apply the knowledge that I have learned in vocational schools and in college.
This project uses tools, namely:
1.ESP8266
2.ACS712 Current Sensor
3.AC Voltage Sensor ZMPT101B
4.Base Plate Nodemcu
5.Converter Cable Adapter USB Power 5V
6.Relay Optocoupler High Low Level

This project will be a web-app using flask python, Arduino IDE, MYSQL, HTML, CSS, and Javascript.
The workflow of this project is that the current and voltage sensors will send a pulse signal to esp8266 and will transfer the data to the database and will display the data to the web-app.
Furthermore, project planning will have features that will be updated.
